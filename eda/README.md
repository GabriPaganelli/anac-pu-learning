# EDA — Analisi Esplorativa

Analisi esplorativa dei dati per il progetto di *Positive-Unlabeled Learning* su appalti pubblici ANAC.

## Struttura

```
eda/
├── eda.R       # Script unico: tutti i grafici 01–18 + landscape PDF
├── cache/      # Coordinate UMAP intermedie (coords_M*.rds), generate da eda.R
└── plots/      # Output grafici (PNG + PDF)
```

## Script

### `eda.R` — Script unico (grafici 01–18 + landscape)

Contiene sia la panoramica descrittiva (01–09) sia gli indicatori forensi e la proiezione UMAP (10–18).
Il blocco UMAP (~8–15 min, ~4 GB RAM picco) richiede `uwot` e `cluster`; le coordinate vengono
salvate in `cache/` per riuso.

| # | File | Contenuto |

| 04 | `04_importi_procedura.png` | Ridge plot importi per procedura + heatmap procedura × quartile importo |
| 05 | `05_competizione_M2.png` | Scatter ribasso vs offerenti con densità marginali (M2) |

| — | `umap_landscape.pdf` | Landscape 4×3 ad alta risoluzione per il report LaTeX |

## Esecuzione

Dalla root del progetto:

```bash
Rscript eda/eda.R   # ~20–40 min (include UMAP + landscape)
```

Da RStudio: aprire lo script e fare `source()` con working directory impostata alla root del progetto.

> **Nota UMAP**: il blocco UMAP calcola la distanza di Gower su ~12k punti per modello (~1.2 GB RAM per matrice). Le coordinate vengono salvate in `cache/` per riuso. Se si vuole solo rigenerare il landscape senza ricalcolare la UMAP, caricare i `.rds` da `cache/` direttamente.


## Note metodologiche

- **Labeled**: ~2600 contratti con etichetta certa (781 condannati, 1817 assolti su M1).
- **Unlabeled**: ~9.47M contratti senza etichetta — nei grafici UMAP viene usato un campione di 10.000 per modello.
- **Regione**: non è nella colonna dei modelli nativi — viene unita in proiezione da `bando_cig_all.parquet`.
- **UMAP**: usa distanza di Gower (adatta a feature miste) + k-NN esatti precomputati; non usa il backend Annoy per garantire riproducibilità con NA.
- **ribasso_spread** (89% NA) è incluso nella feature signature (plot 02) ma escluso dalla proiezione UMAP di M2/M3.

# EDA — Exploratory Data Analysis

Exploratory analysis for the Positive-Unlabeled Learning project on Italian public procurement (appalti pubblici) data from ANAC.

## Structure

```
eda/
├── eda.R       # Single script: all plots 01–18 + landscape PDF
├── cache/      # Intermediate UMAP coordinates (coords_M*.rds), generated by eda.R
└── plots/      # Plot output (PNG + PDF)
```

## Script

### `eda.R` — Single script (plots 01–18 + landscape)

Contains both the descriptive overview (01–09) and forensic indicators plus UMAP projection (10–18).
The UMAP block (~8–15 min, ~4 GB RAM peak) requires `uwot` and `cluster`; coordinates are saved in `cache/` for reuse.

| # | File | Content |
|---|------|---------|
| 01 | `01_panoramica_funnel.png` | Funnel M1→M2→M3: labeled examples per phase and dataset composition |
| 02 | `02_feature_signature.png` | Cliff's δ (numeric) and log₂(P/N) (binary) to identify discriminating variables |
| 03 | `03_territorio_socioeconomico.png` | Conviction rate (tasso condanne) by region + scatter vs homicides/unemployment |
| 04 | `04_importi_procedura.png` | Ridge plot of contract amounts (importi) by procedure type + heatmap procedure × amount quartile |
| 05 | `05_competizione_M2.png` | Scatter discount rate (ribasso) vs number of bidders (offerenti) with marginal densities (M2) |
| 06 | `06_anomalie_M3.png` | Severity score of execution anomalies (anomalie esecutive) and frequency of individual anomalies (M3) |
| 07 | `07_missingness_signal.png` | % NA per feature in P vs N — MNAR test |
| 08 | `08_timeline.png` | % convicted over time (Wilson CI) + annual procedure mix |
| 09 | `09_leakage_watch.png` | flag_delega and importo_complessivo_gara by phase — leakage-risk variables |
| 10 | `10_benford_law.png` | Benford's Law on the first digit of importo_lotto (Nigrini 2012) |
| 11 | `11_threshold_bunching.png` | Bunching at the 40k/150k thresholds of the Italian Procurement Code (Codice Appalti) |
| 12 | `12_CRI_fazekas.png` | Corruption Risk Indicators (Fazekas et al. 2016) |
| 13 | `13_bid_rigging.png` | Bid-rigging indicators OECD/Imhof on M2 |
| 14 | `14_sanita_deepdive.png` | Corruption exposure of the healthcare (SANITA) sector |
| 15 | `15_labeled_temporal_distribution.png` | Temporal distribution of labeled contracts |
| 16 | `16_missing_heatmap_m1.png` | % NA heatmap per M1 feature (P vs N vs U) |
| 17 | `17_tasso_condanne_regione.png` | Conviction rate by region with Wilson confidence intervals |
| 18 | `18_umap_grid.png` | UMAP Gower — 3×2 grid: label + procedure type for M1/M2/M3 |
| — | `umap_landscape.pdf` | High-resolution 4×3 landscape for the LaTeX report |

## Usage

From the project root:

```bash
Rscript eda/eda.R   # ~20–40 min (includes UMAP + landscape)
```

From RStudio: open the script and `source()` with working directory set to the project root.

> **UMAP note**: the UMAP block computes Gower distance on ~12k points per model (~1.2 GB RAM for the matrix). Coordinates are saved in `cache/` for reuse. To regenerate only the landscape without recomputing UMAP, load the `.rds` files from `cache/` directly.

## Methodological notes

- **Labeled**: ~2600 contracts with confirmed label (781 convicted / condannati, 1817 cleared / assolti on M1).
- **Unlabeled**: ~9.47M contracts without label — UMAP plots use a sample of 10,000 per model.
- **Regione** (region): not in the native model columns — joined in projection from `bando_cig_all.parquet`.
- **UMAP**: uses Gower distance (suitable for mixed features) + exact pre-computed k-NN; does not use the Annoy backend to guarantee reproducibility with NA values.
- **ribasso_spread** (89% NA) is included in the feature signature (plot 02) but excluded from the UMAP projection for M2/M3.
